# دعوة فرحنا — GitHub Pages

دعوة عربية ثابتة بـHTML وCSS وJavaScript، من غير مكتبات أو سيرفر خاص.

## تشغيل وتخصيص الدعوة

افتحوا `index.html` للمعاينة المحلية. عدّلوا الأسماء والتاريخ والمكان ورقم واتساب في `wedding-config.js`. رقم واتساب يكتب بأرقام دولية فقط، من غير علامة +، مثل `2010xxxxxxx`.

## النشر من GitHub

المشروع مجهز بـGitHub Actions. بعد رفع التغييرات إلى فرع `main)، يبني الموقع الملفات تلقائيًا وينشر مجلد `dist/` على GitHub Pages. في إعدادات المستودع اختاروا **Settings → Pages → Build and deployment → Source: GitHub Actions**. استخدموا `npm run build` محليًا لتجهيز نفس مجلد النشر؛ لا يوجد `npm install` أو dependencies.

المسارات نسبية، لذلك تعمل الصفحة على رابط GitHub Pages الخاص بالمستودع.

## تأكيد الحضور

النموذج يجهز رسالة تأكيد ويفتحها في WhatsApp؛ لا يخزن الموقع ردودًا. أضيفوا رقم التواصل في `wedding-config.js` لتفعيل الزر. من غير رقم، تظهر رسالة واضحة بدل إرسال رد وهمي.
